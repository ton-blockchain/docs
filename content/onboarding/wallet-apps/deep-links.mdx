---
title: "Deep links"
---

Deep links allow directing users from a dApp to a meaningful location within a TON wallet and invoking corresponding actions.

Choose a link based on what the user needs to do:

| Goal                                             | Format                                                            |
| ------------------------------------------------ | ----------------------------------------------------------------- |
| Prepare a one-time payment                       | [`ton://transfer/...`, Deep links invoices](#deep-links-invoices) |
| Connect a dApp to a wallet                       | [`tc://?...`, TON Connect invoices](#ton-connect-invoices)        |
| Target a specific wallet, such as Telegram Money | [Wallet-specific links](#wallet-specific-invoices)                |
| View an account, transaction, or block           | [Explorer links](#explorer-links)                                 |

## TON Connect invoices

Use TON Connect when a dApp needs a persistent wallet connection and responses to transaction or signing requests.

```bash
tc://?v=2&id=<ID>&r=<REQUEST>
```

**Advantages**

- Persistent communication channel with the wallet.
- Users only need to connect once per session.
- Can track transactions on-chain using the [returned BoC](/applications/ton-connect/how-to/message-lookup).
- Ready-made SDKs and UI kits for various platforms.

**Disadvantages**

- If only one payment is needed, users must connect the wallet and confirm the transaction.
- More complex integration than a `ton://` link.

See [TON Connect universal links](/applications/ton-connect/core-concepts#universal-links) for parameter definitions and other TON Connect link formats.

<Callout type="note">
  Most Telegram clients support opening `tc://` links from outside Telegram, but the operating system may open another registered wallet. To target Telegram Money, use its [Telegram-specific TON Connect links](#ton-connect-in-telegram).
</Callout>

## Deep links invoices

The `ton://` scheme is part of the broader standard, enabling interoperability across different TON-based wallets and services.

<Callout type="caution">
  The `ton://` link is less common in the ecosystem than `tc://`, but it may be useful for a simple, one-time payment flow.
</Callout>

```bash
ton://transfer/<ADDRESS>
```

**Advantages**

- Easy integration.
- No need to connect a wallet.

**Disadvantages**

- Users must scan a new QR code for each payment.
- Cannot track if the user signed the transaction.
- No information about the user's address.
- Requires workarounds for platforms where links are not clickable (e.g., Telegram Desktop bots).

### Example workflows

- **Quick payments:** Open a pre-filled payment request from a website using a `ton://` link.
- **In-app transactions:** Open a wallet's send screen from an application.
- **Link to specific transfers:** Use [explorer links](#explorer-links) to open and review a single transaction.

### Gram transfer

Opens the pre-filled send screen and prompts the user to enter the missing data.

```bash title="Transfer scheme"
ton://transfer/<ADDRESS>?amount=<AMOUNT>&text=<TEXT>
```

| Parameter   | Description                                                 | Required |
| ----------- | ----------------------------------------------------------- | -------- |
| `<ADDRESS>` | The recipient's TON address.                                | required |
| `<AMOUNT>`  | The amount of Gram to send, in nanograms.                   | optional |
| `<TEXT>`    | A URL-encoded UTF-8 text message to attach to the transfer. | optional |

#### Gram transfer to address

```bash title="scheme"
ton://transfer/<ADDRESS>
```

```bash title="example"
ton://transfer/UQDYzZmfsrGzhObKJUw4gzdeIxEai3jAFbiGKGwxvxHinf4K
```

#### Gram transfer with amount

```bash title="scheme"
ton://transfer/<ADDRESS>?amount=<AMOUNT>
```

```bash title="example"
ton://transfer/UQDYzZmfsrGzhObKJUw4gzdeIxEai3jAFbiGKGwxvxHinf4K?amount=5000000

```

#### Gram transfer with text comment

```bash title="scheme"
ton://transfer/<ADDRESS>?text=<TEXT>
```

```bash title="example"
ton://transfer/UQDYzZmfsrGzhObKJUw4gzdeIxEai3jAFbiGKGwxvxHinf4K?text=hello
```

#### Gram Transfer with amount and text comment

```bash title="scheme"
ton://transfer/<ADDRESS>?amount=<AMOUNT>&text=<TEXT>
```

```bash title="example"
ton://transfer/UQDYzZmfsrGzhObKJUw4gzdeIxEai3jAFbiGKGwxvxHinf4K?amount=5000000&text=hello
```

### Transfer with expiry timestamp

Opens the send screen with an expiry timestamp `exp` for the transaction — the blockchain would reject transactions past that timestamp.

```bash title="Scheme with timestamp"
ton://transfer/<ADDRESS>?amount=<AMOUNT>&text=<TEXT>&exp=<EXPIRY_TIMESTAMP>
```

| Parameter            | Description                                                 | Required |
| -------------------- | ----------------------------------------------------------- | -------- |
| `<ADDRESS>`          | The recipient's TON address.                                | required |
| `<AMOUNT>`           | The amount of Gram to send, in nanograms.                   | optional |
| `<TEXT>`             | A URL-encoded UTF-8 text message to attach to the transfer. | optional |
| `<EXPIRY_TIMESTAMP>` | Expiry timestamp in seconds since the Unix epoch.           | optional |

#### Gram transfer with expiry timestamp

```bash title="scheme transfer with expiry"
ton://transfer/<ADDRESS>?amount=<AMOUNT>&text=<TEXT>&exp=<EXPIRY_TIMESTAMP>
```

```bash title="example transfer with expiry"
ton://transfer/EQD2NmD_lH5f5u1Kj3KfGyTvhZSX0Eg6qp2a5IQUKXxOG21n?amount=100000&text=test&exp=2147483647
```

### Jetton transfer

Opens the send screen with a [jetton](/contracts/standard/tokens/jettons/overview) transfer. Jetton is a standard for fungible assets on TON, like USDT or other tokens.

```bash title="scheme"
ton://transfer/<ADDRESS>?jetton=<JETTON_ADDRESS>&amount=<AMOUNT>&text=<TEXT>
```

| Parameter            | Description                                                 | Required |
| -------------------- | ----------------------------------------------------------- | -------- |
| `<ADDRESS>`          | The recipient's TON wallet address.                         | required |
| `<JETTON_ADDRESS>`   | The jetton master address.                                  | required |
| `<AMOUNT>`           | The amount of jettons to send.                              | optional |
| `<TEXT>`             | A URL-encoded UTF-8 text message to attach to the transfer. | optional |
| `<EXPIRY_TIMESTAMP>` | Expiry timestamp in seconds since the Unix epoch.           | optional |

<Callout type="tip">
  One whole Jetton for `<AMOUNT>` is defined by

  - [`decimals`](/contracts/standard/tokens/metadata#decimals) the number of fractional digits
  - `unit` that represents the smallest indivisible amount of the token (similar to satoshi in Bitcoin).

  <Accordions>
    <Accordion
      title="Read more..."
    >
      $$
      \text{One whole Jetton} = unit \times 10^{decimal}
      $$

      For example, a USDT Jetton on TON defines decimals = 6.
      This means:

      $$
      1\ \text{USDT} = 1{,}000{,}000\ \text{smallest units}
      $$

      Or, in general form:

      $$
      \text{One whole USDT} = unit \times 10^{6}
      $$

      Typically Jetton on TON defines with decimals = 9, for example, DUST jetton.
      This means:

      $$
      1\ \text{DUST} = 1{,}000{,}000{,}000\ \text{smallest units}
      $$

      Or, in general form:

      $$
      \text{One whole DUST} = unit \times 10^{9}
      $$
    </Accordion>
  </Accordions>
</Callout>

#### Transfer default jetton

Typically, jetton decimals in amount are equal 9 and evaluation same as for Gram.

```bash title="scheme"
ton://transfer/<ADDRESS>?jetton=<JETTON_ADDRESS>&amount=<AMOUNT>&text=<TEXT>
```

```bash title="example transfer 0.005 DUST"
ton://transfer/UQDYzZmfsrGzhObKJUw4gzdeIxEai3jAFbiGKGwxvxHinf4K?jetton=EQBlqsm144Dq6SjbPI4jjZvA1hqTIP3CvHovbIfW_t-SCALE&amount=5000000&text=hello
```

#### Transfer USDT

While Gram requires nine decimal places and 1 Gram equals 1 billion ($10^9$) nanograms, USDT only uses six decimal places. This means that 1 USDT unit stands for 1 million ($10^6$) microUSDT units. The `AMOUNT` below requires the microUSDT format.

```bash title="scheme"
ton://transfer/<ADDRESS>?jetton=<JETTON_ADDRESS>&amount=<AMOUNT>&text=<TEXT>
```

```bash title="example transfer 0.005 USDT"
ton://transfer/UQDYzZmfsrGzhObKJUw4gzdeIxEai3jAFbiGKGwxvxHinf4K?jetton=EQCxE6mUtQJKFnGfaROTKOt1lZbDiiX1kCixRv7Nw2Id_sDs&amount=5000&text=hello
```

### Transfer with binary data

Opens the emulation screen or screen with alert about blind signing transactions with amount and destination.

```bash title="scheme"
ton://transfer/<ADDRESS>?amount=<AMOUNT>&bin=<BINARY_DATA>
```

| Parameter       | Description                                                                    | Required |
| --------------- | ------------------------------------------------------------------------------ | -------- |
| `<ADDRESS>`     | The recipient's TON address.                                                   | required |
| `<AMOUNT>`      | The amount of Gram to send, in nanograms.                                      | optional |
| `<BINARY_DATA>` | A URL-encoded base64 BoC which will be attached as a body to internal message. | optional |

## Wallet-specific invoices

Use specific links for each wallet to initiate jetton and Gram transfers. The format usually resembles `ton://transfer` links, but make sure to consult the documentation for each wallet.

Example: transferring 1 USDT to `EQCxE6mUtQJKFnGfaROTKOt1lZbDiiX1kCixRv7Nw2Id_sDs`:

```bash title="MyTonWallet"
https://my.tt/transfer/UQDYzZmfsrGzhObKJUw4gzdeIxEai3jAFbiGKGwxvxHinf4K?amount=1000000&jetton=EQCxE6mUtQJKFnGfaROTKOt1lZbDiiX1kCixRv7Nw2Id_sDs
```

### Telegram Money

[Telegram Money](/onboarding/wallet-apps/telegram) links open the native wallet in the installed Telegram app, including when opened from another app or a browser.

```bash title="Open Telegram Money"
tg://sendgrams
```

The HTTPS form, `https://t.me/sendgrams`, accepts the same parameters as the `tg://sendgrams` deep link.

<Callout type="tip">
  Telegram Money also handles regular [Gram transfer links](#gram-transfer) on mainnet.
</Callout>

<Callout type="note">
  The `tg://ton` link opens Telegram's separate TON balance screen, associated with [channel monetization](https://telegram.org/blog/monetization-for-channels). It does not open Telegram Money.
</Callout>

#### Gram transfer in Telegram

Add `to` and optionally `amount` to prepare a transfer:

```bash title="scheme"
tg://sendgrams?to=<RECIPIENT>&amount=<AMOUNT>
```

| Parameter     | Description                                                                                                     | Required |
| ------------- | --------------------------------------------------------------------------------------------------------------- | -------- |
| `<RECIPIENT>` | An `@username` or a mainnet TON address in raw or URL-safe friendly format.                                     | required |
| `<AMOUNT>`    | A positive decimal amount in Gram, using ASCII digits and `.` with at most nine fractional digits, e.g., `1.5`. | optional |

- For `@username`, the recipient must be another ordinary Telegram user.
- TON address recipients can use wallets outside Telegram.
- TON DNS names such as `alice.ton` are **not resolved**.

Supply each parameter once, using lowercase names. Omit the amount to use its default value: `0`.

```bash title="1.5 Gram"
tg://sendgrams?to=@monk&amount=1.5
tg://sendgrams?to=UQDYzZmfsrGzhObKJUw4gzdeIxEai3jAFbiGKGwxvxHinf4K&amount=1.5
```

#### TON Connect in Telegram

These links open Telegram Money's native TON Connect flow:

```bash title="Telegram Money TON Connect"
tg://sendgrams?startapp=tonconnect-<PACKED>
tg://resolve?domain=sendgrams&startapp=tonconnect-<PACKED>
https://t.me/sendgrams?startapp=tonconnect-<PACKED>
```

There, `<PACKED>` is a [TON Connect query](/applications/ton-connect/core-concepts#universal-links) encoded for Telegram's `startapp` parameter. For packing and reopening pending requests, see how to [create TON Connect links for Telegram Money](/onboarding/wallet-apps/telegram#create-ton-connect-links).

## Explorer links

[Actonscan](/onboarding/explorers#actonscan) links can open accounts, transactions, and blocks by providing their respective values:

- `<ADDRESS>` is a raw or user-friendly TON address,
- `<TRANSACTION_HASH>` is a hexadecimal transaction hash,
- and `<WORKCHAIN>`, `<SHARD>`, and `<SEQNO>` identify a block.

The low-level [TON Explorer](https://explorer.toncoin.org/) only provides direct links to transactions — they require an account address, logical time (`lt`), and a transaction hash. Obtain these values by calling the [`getTransactions`](https://toncenter.com/api/v2/#/transactions/get_transactions_getTransactions_get) API endpoint. Convert the hexadecimal transaction hash to uppercase before composing a link.
