title: "How to run a TON forward proxy"

Run a local forward proxy to access TON Sites from a browser. Choose either Tonutils-Proxy or the C++ `rldp-http-proxy`.

## Prerequisites

- For C++: extract `rldp-http-proxy` from the archive for your platform in [TON v2026.08](https://github.com/ton-blockchain/ton/releases/tag/v2026.08) into your working directory. The separate `http-proxy` download is a different program.
- For C++: save the [mainnet global configuration](https://ton-blockchain.github.io/global.config.json) as `global.config.json` in the same directory.

## Use Tonutils-Proxy

[Tonutils-Proxy](https://github.com/xssnick/Tonutils-Proxy) is a community-developed open-source forward proxy.

On Linux (x86-64), download and run version 1.8.3:

```bash
wget https://github.com/xssnick/Tonutils-Proxy/releases/download/v1.8.3/tonutils-proxy-cli-linux-amd64
chmod +x tonutils-proxy-cli-linux-amd64
./tonutils-proxy-cli-linux-amd64
```

For other platforms, use the corresponding CLI binary from the [same release](https://github.com/xssnick/Tonutils-Proxy/releases/tag/v1.8.3).

The proxy listens on `127.0.0.1:8080` and loads the mainnet configuration automatically. It also forwards ordinary HTTP requests. Append `--no-http` to the startup command to block those requests. See [Tonutils-Proxy options](/foundations/web3/ton-proxy/reference#tonutils-proxy-options).

## Use rldp-http-proxy

<Callout
  type="caution"
  title="HTTP listener exposure"
>
  The C++ proxy listens on all network interfaces. For local use, block inbound TCP connections to port `8080` on non-loopback interfaces with your host firewall. Configuring the browser to use localhost does not restrict the listener. Tonutils-Proxy binds to loopback by default.
</Callout>

Run the extracted C++ binary:

```bash
chmod +x rldp-http-proxy
./rldp-http-proxy -p 8080 -c 3333 -C global.config.json
```

The proxy uses UDP port `3333` for ADNL traffic. See the [C++ CLI options](/foundations/web3/ton-proxy/reference#forward-proxy-options) to change these values.

## Connect the browser

Keep your chosen proxy running and configure the browser's HTTP proxy to use `127.0.0.1` on port `8080`. Run only one of these proxies on that port at a time.

## Verify

Open `http://<DOMAIN>` in the configured browser, replacing `<DOMAIN>` with the full `.ton` name of a running TON Site. Confirm that the expected page loads.

For direct access without DNS, open `http://<ADNL_ADDRESS>.adnl`, replacing `<ADNL_ADDRESS>` with the site's user-friendly ADNL address.

## Troubleshoot

| Problem                                 | Check                                                                                                                                                         |
| --------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Browser cannot connect to the proxy     | Check that the process is running and the browser uses port `8080`.                                                                                           |
| A `.ton` site cannot be reached         | Check the domain's `site` record and whether its destination is online.                                                                                       |
| An ordinary Internet domain is rejected | The C++ proxy accepts only `.ton`, `.adnl`, and `.bag` destinations by default. With Tonutils-Proxy, check whether `--no-http` is enabled.                    |
| `storage gateway is not set`            | For the C++ proxy, configure a [Storage gateway](/foundations/web3/ton-proxy/storage-gateway#use-rldp-http-proxy) for a destination that resolves to a BagID. |
