TON Storage is a distributed file storage system on the TON Network. Files are shared using a torrent-like protocol, with optional on-chain smart contracts for paid storage.

## Bags and integrity

Files are organized into _bags_, each identified by a unique 256-bit `BagID`, the hash of the torrent info cell. A bag can contain a single file or a directory.

A Merkle tree built from SHA-256 hashes allows verification of individual pieces without downloading the full bag. This verification does not require a paid storage contract.

Bags are immutable. Changing their contents requires creating a new bag with a new BagID. The identifier also depends on metadata, including the bag description.

## File distribution

TON Storage uses the TON DHT to discover peers for a bag. Peers exchange pieces of the bag, allowing downloads from multiple nodes.

The official implementation provides `storage-daemon` and `storage-daemon-cli` to create, download, and share bags. Downloaded data is shared with other peers by default; sharing can be paused or disabled.

Files remain available while peers retain and serve the required data.

## Paid storage

A storage provider stores bags for a fee. A client requests storage through the provider's smart contract and funds a separate storage contract for the bag.

The provider submits Merkle proofs to the storage contract to receive payment for storing the data. These proofs establish possession of the challenged data; the contract does not verify that the provider serves download requests.

## Ecosystem integration

- [TON DNS](/foundations/web3/ton-dns): associates a domain name with a BagID.
- [TON Sites](/foundations/web3/ton-sites): uses bags to store static website files, accessed through a Storage gateway.
- [Blockchain archives](/nodes/cpp/run-archive-liteserver): uses TON Storage to distribute historical blocks and state snapshots.
